# Codveda Technologies Java Development Internship

## Level 3 - Task 3: Binary Search Tree Implementation

### Project Overview
This project implements a Binary Search Tree (BST) using Java. It provides operations for inserting, searching, deleting nodes, and performing tree traversals.

### Features
- Insert nodes into BST
- Search for a node
- Delete nodes
- In-order traversal
- Pre-order traversal
- Post-order traversal
- Menu-driven console application

### Technologies Used
- Java
- Data Structures
- Binary Search Tree
- Recursion

### Concepts Learned
- Tree data structure
- Recursive methods
- Node management
- Searching and insertion
- Deletion in BST
- Tree traversal techniques

### How to Run

Compile:
javac BinarySearchTree.java

Run:
java BinarySearchTree
