# Codveda Technologies Java Development Internship

## Level 2 - Task 1: Employee Management System

### Project Overview
The Employee Management System is a console-based Java application developed as part of the Codveda Technologies Java Development Internship.

The application manages employee records and provides basic CRUD (Create, Read, Update, Delete) functionality through a menu-driven interface.

### Features
- Add new employee records
- View all employees
- Search employee by ID
- Update employee details
- Delete employee records
- Menu-driven console interface

### Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Scanner

### Concepts Applied
- Classes and Objects
- Encapsulation
- Constructors
- Getters and Setters
- ArrayList
- CRUD Operations
- Loops and Conditional Statements

### Project Structure
- Employee.java: Represents employee data and its related methods.
- EmployeeManagementSystem.java: Implements the application menu and employee management operations.

### How to Run

Compile:

javac Employee.java EmployeeManagementSystem.java

Run:

java EmployeeManagementSystem
