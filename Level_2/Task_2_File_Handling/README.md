# Codveda Technologies Java Development Internship

## Level 2 - Task 2: File Handling Application

### Project Overview
This is a menu-driven Java application that performs basic file handling operations.

### Features
- Create a file
- Write content to a file
- Read file content
- Append content to an existing file

### Technologies Used
- Java
- File Handling
- FileWriter
- FileReader
- BufferedReader
- Exception Handling

### How to Run
Compile:
javac FileHandling.java

Run:
java FileHandling
